# Ebin Antony Elenjikkal — Portfolio Website

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or installation are required. This is a standalone HTML, CSS and JavaScript website.

## Before publishing
- Replace the profile placeholder with your own photo.
- Replace `YOUR_EMAIL@example.com` with your professional email.
- Replace `YOUR-LINKEDIN` with your LinkedIn profile URL.
- Add your resume as `resume.pdf` in the same folder.
- Add project screenshots and certificates. Update the project visual blocks or add `<img>` elements.
- Verify all dates, project details and experience descriptions before publishing.

## Deploy
You can upload this folder to GitHub Pages, Netlify or any static website hosting provider.
